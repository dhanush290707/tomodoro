# 🍅 Pomodoro Timer

A beautiful, feature-rich Pomodoro timer web application built with React and Vite.

![Pomodoro Timer Screenshot](https://raw.githubusercontent.com/dhanush290707/tomodoro/main/screenshots/dark-theme.png)

## ✨ Features

- ⏱️ **Circular Timer** - Beautiful SVG progress ring with smooth animations
- 🎯 **Multiple Modes** - Focus (25m), Short Break (5m), Long Break (15m)
- ⚙️ **Customizable Settings** - Adjust durations, auto-start options, volume
- 🌓 **Dark/Light Theme** - Toggle between themes with smooth transitions
- ✅ **Task List** - Track what you're working on
- 📊 **Statistics** - Session counts, streaks, and weekly progress chart
- 🔔 **Sound Notifications** - Audio alerts when sessions complete
- ⌨️ **Keyboard Shortcuts** - Space (play/pause), R (reset), S (skip)
- 💾 **Persistent Storage** - All data saved to localStorage

## 🛠️ Tech Stack

- **React 19** - UI library
- **Vite** - Build tool
- **Lucide React** - Icons
- **CSS Variables** - Theming
- **Web Audio API** - Sound notifications

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/dhanush290707/tomodoro.git

# Navigate to directory
cd tomodoro

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🌐 Deployment

Deploy to GitHub Pages:

```bash
npm run deploy
```

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause timer |
| `R` | Reset timer |
| `S` | Skip to next session |
